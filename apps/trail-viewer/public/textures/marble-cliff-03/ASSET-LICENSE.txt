Runtime derivative
------------------

Downscaled from the source 1K maps to 512x512 via Blender 5.2
(--background --python) — same pipeline and same reason as
rocky-terrain-02 (ffmpeg's EXR decoder doesn't implement single-channel
"Gray DWA" compression, which this asset's normal map uses; silently
decodes to all-zero instead of erroring).

Only diff and nor_gl are used (this asset feeds Babylon's TerrainMaterial
as the "steep" slope layer — a legacy material with diffuseTexture/
bumpTexture slots only, no roughness/displacement, so disp and rough were
not converted). nor_gl colorspace set to Non-Color before saving (no sRGB
curve applied). This derivative is also available under CC0.
