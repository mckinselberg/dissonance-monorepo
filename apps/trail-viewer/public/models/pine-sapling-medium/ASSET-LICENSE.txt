Runtime derivative
------------------

Only a 4K glTF was available for this asset (no 1K variant), so its six 4K
JPEG textures were downscaled to 1024x1024 with ffmpeg first (gltfpack's
node.js build can't do texture processing itself — that needs -tc/-tu/-tw,
none of which the node.js build supports), then simplified with gltfpack 1.2:

  gltfpack -i pine_sapling_medium_4k.gltf -o pine_sapling_medium_preview.glb -si 0.009 -sp -kn -km

Reduces the model from 6,038,139 to 62,147 triangles (three separate
bark/twig/dead-branches meshes) and packages it as one GLB for the browser
preview. Needed a much lower -si ratio than tree_small_02's 0.025 since the
source model is roughly 3x heavier to begin with. This derivative is also
available under CC0.

Bark diffuse was further color-normalized (2026-07-23) against the other
tree species' bark/wood textures — see tree-small-02's ASSET-LICENSE.txt
for the full pipeline description. Twig diffuse was deliberately left
untouched (alpha-cutout card atlas, not a simple scan).

Meshopt runtime compression is intentionally disabled for this preview so the
Babylon client does not need to fetch a decoder from an external CDN.
