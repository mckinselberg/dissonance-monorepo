Runtime derivative
------------------

Only a 4K glTF was available for this asset (no 1K variant), so its three
4K JPEG textures were downscaled to 1024x1024 with ffmpeg first (gltfpack's
node.js build can't do texture processing itself — that needs -tc/-tu/-tw,
none of which the node.js build supports), then simplified with gltfpack 1.2:

  gltfpack -i tree_stump_01_4k.gltf -o tree_stump_01_preview.glb -si 0.3 -sp -kn -km

Reduces the model from 41,046 to 12,312 triangles and packages it as one GLB
for the browser preview. This derivative is also available under CC0.

Meshopt runtime compression is intentionally disabled for this preview so the
Babylon client does not need to fetch a decoder from an external CDN.
