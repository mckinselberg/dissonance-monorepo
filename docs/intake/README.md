# Documentation Intake

**Status:** non-canonical inbox  
**Scope:** New ideas, references, prompts, external drafts, and possible project direction awaiting review  
**Last reviewed:** 2026-08-01

This directory is the repository landing zone for new material that has not yet
been reconciled with the Dissonance documentation system.

Material in `docs/intake/` may include:

- new design ideas or changes in direction;
- AI-generated or human-authored prompts;
- reference images and source documents;
- proposed systems, mechanics, locations, or narrative material;
- revisions that may conflict with current canon or implementation.

Presence here does not make an idea accepted, scheduled, or canonical. Intake
material must not be used directly as implementation guidance.

## Triage workflow

1. Identify the concept's owning thread or propose a new stable thread ID.
2. Compare it with `DECISIONS.md`, `OPEN-QUESTIONS.md`, canonical design documents,
   `SYSTEMS.md`, `THREADS.md`, and the current repository implementation.
3. Surface conflicts and unresolved forks; do not resolve them silently.
4. Fold accepted behavior into exactly one canonical document.
5. Register consequential decisions and open questions by stable ID.
6. Create or revise an engineering prompt only after design and ownership are clear.
7. Move the original intake artifact to an appropriate archive/source location once
   reconciliation is complete.

Reference assets may remain here while their owning domain is unknown. Once the
domain is established, move them beside the relevant canonical design document.
